# セッションボード v0.2.7 の掲載画像

撮影はPlaywrightとChromiumで行った。配布物のパネルと同じJavaScript・CSSを読み込み、ローカルの撮影用ページから架空の取得結果を渡した。ワーカーの実データやOrca本体のウィンドウは撮影に使用していない。Codex内蔵ブラウザは新規タブ作成時に `The browser access host is unavailable` を返した。

| 画像 | 確認した表示 |
| --- | --- |
| [カバー](../../assets/cover.png) | 入力待ち、作業中、完了を横並びにしたダークテーマのボード |
| [一覧](../../assets/list.png) | Botの仕事と通常セッションを状態でまとめたリスト |
| [ボード](../../assets/board.png) | ボードへの切り替えとライトテーマでの3列表示 |
| [詳細](../../assets/activity.png) | 未回答の質問、回答ボタン、Activity。撮影前に状態履歴との切り替えも確認 |

各画像の原寸と幅384px相当の縮小表示を確認した。画面内の時刻、セッション名、会話は撮影用データであり、PNGから付随メタデータを除去した。
