# 折りたたまれた項目グループからの標準返信

macOS版 Orca 1.4.277 のネイティブ画面を Orca Computer Use で確認した。Community ミラーから正式導入した公開キー `yoshhiide.session-board` v0.2.10 と別キーのフォルダ版 v0.2.6 が同時に稼働していた。公開タグとミラーの配布物はコミット `dc347eec5e18ac0ffd2fff344036bb08a268155e` と配布ハッシュ `85cf337a6da2ff9e117634ca7c6c0162a2fb3750ca2e8ddb5f33601ae6b3b69b` で一致した。

公開パネルから、別Botを起点に通常の一覧返信と、詳細にある2問目への回答を操作した。対象Botがメインの2項目では、標準のコメント欄と選択した質問の入力欄にそれぞれフォーカスした。Updaterの予定項目では、別Botから Updater のHome Chatへ移動し、標準のホームを表示した時点で止まった。Updaterを開いた状態から試しても、予定グループが折りたたまれている間は同じ位置で止まった。プラグインの画面が標準のホームに切り替わったため、停止時に失敗メッセージは画面に表示されなかった。

OrcaのAXツリーでは、折りたたまれた予定の見出しの隣に `button Planned 1` があり、項目行は存在しなかった。v0.2.10は `button (collapsed)` だけを展開の候補にした。実機で `Planned 1` を展開すると `button (expanded)`、`content list Planned` と対象の項目行が表示され、同じ公開パネルの返信ボタンから標準コメント欄にフォーカスした。3項目とも下書きを入力してから消去し、送信せずに確認した。

v0.2.11 は対象のグループ見出しと同じ位置にある件数付きの展開ボタンを照合して押す。その後も対象Bot、項目番号とタイトル、状態、フォーカスを読み戻す。項目グループまたはウィンドウで停止した場合をパネルのメッセージとワーカーログで区別できる。

## ワークスペースと表示言語

通常のワークスペースタブでは、最初のAXにBot Homeが存在しなかった。日本語の v0.2.10 はその状態からメインの2問目を開けた。英語の v0.2.10 は同じ起点から Updater のHomeへ移動したが、閉じた予定一覧で停止した。単一の表示中ウィンドウで検証し、複数ウィンドウや別Spaceにあるウィンドウは実機検証の範囲外。

GitHubから v0.2.11 のタグアーカイブを再取得し、配布ハッシュ `7d39dd825afda07cf3f0602cf281f2a6e51d736b8dd5805a6d0667a64b28e92e` とバンドルの一致を確認した。そのバンドルのワーカーを実機で動かすと、日本語と英語のどちらも `Planned 1` の展開、予定項目の表示、コメント欄のフォーカスまで進んだ。架空の下書きは入力後に消去し、言語設定と予定一覧の開閉状態を元に戻した。型検査、ビルド、Orcaの25テスト、配布物検証、GitHubのコミット・タグ署名検証が通過した。

## Community 正式導入版の最終確認

Communityの通常更新で導入した `yoshhiide.session-board` v0.2.11 は、コミット `bc75f908716e08708a4015f708353f2107d20fa0`、上記の配布ハッシュ、`running` を確認した。取得元がミラーから作者のリポジトリへ戻ったため、Orcaの通常の承認を経て更新した。フォルダ版 v0.2.6 と併存する状態で、公開キーのパネルを選んだ。

- 別Botを開き、Updater の予定グループで `Planned 1` を確認してから、公開パネルの #22 の「返信」を押した。Updater へ切り替わり、予定グループが開いて #22 の標準コメント欄へフォーカスした。架空の下書きを入力して消去した。
- Updater を開いた状態から、公開パネルの #21 の「返信」で詳細を表示し、2問目「形」の「標準画面で回答」を押した。対象Botへ切り替わって #21 が開き、`Replying to` が「形」を指すこと、回答欄へのフォーカスを確認した。架空の下書きを入力して消去した。

どちらも日本語設定、表示中のOrcaウィンドウ1つで確認した。項目の最終イベントIDは操作の前後で一致した。予定グループを検証前の折りたたみ状態に戻した。別マシン、複数ウィンドウ、別Space、他言語のインストール済みパネルはこの確認の対象外。
